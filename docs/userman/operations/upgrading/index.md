Taipy is an active library that is continuously evolving. To keep up with the latest
features and improvements, you may need to upgrade your Taipy version to a newer one.
Please refer to the [Taipy release notes](../../../release-notes/index.md) to understand
the changes and improvements in each version.

Even if Taipy tries to maintain backward compatibility as much as possible, some
upgrades to major versions of Taipy require you to update your code or your data.

The following page provides guidance on how to upgrade your Taipy version
[from Taipy 3 to Taipy 4](from-3.X-to-4.Y.md).

For upgrades from non-supported versions, please refer to the
[from Taipy 2 to Taipy 3](from-2.X-to-3.Y.md) or the
[from Taipy 2.0 to Taipy 2.1](from-2.0-to-2.1.md) pages.
